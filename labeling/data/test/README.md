# Final evaluation split

210 pages: 30 each of article, documentation, forum, product, listing, collection, and service.
49,980 resolved binary block labels generated by Gemini 3.5 Flash-Lite.

- `annotations.jsonl`: per page, golden Markdown (content blocks in page order, preserving headings, tables, lists and code), inclusion/exclusion snippets with source offsets, structure checks, and 673 grounded QAs with expected answers, required answer points and evidence.
- `blocks.jsonl`: one block per row with its reference label (content / boilerplate), confidence, reason and model provenance; used for block-level scoring.
- `pages.jsonl`: page metadata (URL, final URL, domain, page type, snapshot id).

The source HTML snapshots are not stored here, so outputs cannot be regenerated from this folder alone; saved outputs are in `eval/outputs/`.

Keep these labels out of training and tuning. References are model-generated, not independent human gold.
There is no training URL, redirect, or identical-snapshot overlap. Domains are shared with dev
(207 of 210 pages), so this evaluates new pages on mostly familiar domains, not unseen-domain generalization.
Page types are URL heuristics. Blocks were verified against `models/blocking.py` on every saved test page.

All 210 pages have completed page annotations. Snippets are exact source spans; inclusion snippets
appear in rendered golden text and exclusion snippets do not. Two pages contain no boilerplate
blocks and therefore have empty exclusion lists. Structure counts were checked against parsed
golden Markdown. For snippet scoring, render Markdown to text before normalizing case and
Unicode alphanumeric characters.

QAs include 256 model-rated hard and 417 medium questions. Grade using `required_answer_points`,
`expected_answer`, and source evidence; filter `difficulty == "hard"` for the harder subset.
Every evidence quote was validated against a selected content block. This verifies grounding
literally, rather than providing an independent semantic review of every answer.
QA provenance records 140 pages from Gemini 3.5 Flash-Lite, 60 from Gemini 3.5 Flash, and ten
completed by Codex in-session after Gemini returned HTTP 402 for depleted credits.

Five pages with unusable content were replaced within their original page types.
