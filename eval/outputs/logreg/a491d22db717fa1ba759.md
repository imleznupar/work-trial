# New build not available through apt

I’m getting a popup telling me that there’s a new build available. I installed Sublime Text through apt, as instructed for Debian, but that repository doesn’t seem have the new build available. When will it be available?

I’ve managed to fix it.

There were no errors when I ran apt update, and

```
Hit:4 https://download.sublimetext.com apt/stable/ InRelease
```

was there, so apt thought it already had the latest index. But when I looked at https://download.sublimetext.com/apt/stable/Packages, I did see that it listed the new build for amd64, while apt show -a sublime-text didn’t list it. Wiping /var/cache/apt/ didn’t help, but after removing the entries related to Sublime Text from /var/lib/apt/lists/, apt update finally picked up the new build.

I’ve had this happen once before with a Sublime Text update (but I didn’t check /var/lib/apt/lists at that time, I just waited it out), while other repos don’t seem to have this problem.
