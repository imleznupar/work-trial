# Build modern search and agentic experiences faster

UI components and SDKs that help developers ship high-performing search, discovery, recommendation, and conversational experiences across any device without building every interaction pattern from scratch.

##  Built to unlock the full potential of Algolia’s search infrastructure

Algolia’s UI Component Libraries help you turn powerful search APIs into fast, flexible frontend experiences. Start with proven search and discovery patterns, then extend them into AI-powered and agent-driven interactions with the control your team needs.

##### Search as you type

Show relevant results from the first keystroke, powered by Algolia’s speed and relevance.

##### Federated search

Surface different types of content in a single, unified interface.

##### Filters and facets

Help users narrow results quickly with customizable filtering and faceting components built for real-world catalogs.

##### Sorting & pagination

Give users clear ways to explore results, compare options, and move through large result sets without friction.

##### Recommend

Encourage users to expand their search and browse to find similar or complementary items.

##### Agent Studio SDK components

Build conversational interfaces, guided discovery flows, and agent-assisted workflows that connect search, product data, business logic, and LLM-powered experiences.

Move beyond static search results with components that help users ask questions, refine intent, and discover the next best result faster.

Algolia provides frontend libraries for the frameworks developers already use. Each library follows the concepts, coding patterns, and UX best practices of its framework, so teams can move quickly from a basic search UI to more advanced AI search and agent-driven experiences.  
Build with prebuilt components, compose your own flows, and customize the experience end to end without giving up performance or flexibility.
