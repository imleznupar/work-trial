> How ~~to~~ do I revert back to 7.1?

Kernel 7.1 has reached EOL and **is no longer installable** from Manjaro repositories. Consider kernel 6.18 (LTS) instead.

You might also consider updating the firmware for your machine. Beyond that, I’m afraid I have nothing to suggest.

Providing your System Information formatted according to forum guidelines may be helpful. See below. ![:point_down:](https://forum.manjaro.org/images/emoji/twemoji/point_down.png?v=15)

[Mini-HowTo] Provide System Information [Mini-HowTo] Present code or command output

The only solution in that case is a backup done before updating : Timeshift is your friend !

You don’t just revert to an unsupported kernel. It is/will be removed.  
If you cannot solve the problem in some other way - here is an appropriate reading material -

The only way to use exactly 7.1 will be to find a distro that supports it. Untill it gets updated too, in a couple of months of course. So this is a nonsolution.

Better concentrate on fixing the real problem.

You can only revert to an unsupported kernel by building it locally.

Using the topic [[How To] Compile a custom Manjaro kernel](https://forum.manjaro.org/t/how-to-compile-a-custom-manjaro-kernel/186822)

And added benefit is the kernel is being maintained by the package manager using a custom package name, thus not being replaced by an update to the repository kernel

You can amend the script to look like below
    
    
    #!/usr/bin/env bash
    
    ####---- version 14 ----####
    # [date=2026-10-02 time=09:30:00 timezone="Europe/Copenhagen"]
    
    # define manjaro kernel name to work with
    if [[ -z $1 ]]; then
            echo "FAILURE: Kernel must be supplied e.g. 'linux72'."
            exit 1
    else
            manjaro_kernel="$1"
    fi
    
    # define builddir - default to user's home
    # if you change - remember to create the path beforehand
    builddir=$HOME
    
    # define custom kernel identifier
    custom="-custom"
    
    # define custom build host
    host="$(hostnamectl hostname)"
    
    # define custom build user
    user=$USER
    
    # define the kernel configuration path
    kernel_config=${builddir}/${manjaro_kernel}/core/${manjaro_kernel}/config
    
    # define the pkgbuild path
    pkgrecipe=${builddir}/${manjaro_kernel}/core/${manjaro_kernel}/PKGBUILD
    
    # cd into builddir
    cd ${builddir}
    
    # remove ${manjaro_kernel} dir if it exist
    [[ -d ${builddir}/${manjaro_kernel} ]] && rm -rf ${builddir}/${manjaro_kernel}
    
    # clone Manjaro package build recipe
    git clone -n --depth=1 --filter=tree:0 https://code.manjaro.org/packages/PKGBUILDs.git ${builddir}/${manjaro_kernel}
    
    cd ${builddir}/${manjaro_kernel}
    
    git sparse-checkout set --no-cone core/${manjaro_kernel}
    
    git checkout
    
    # change working folder
    cd ${builddir}/${manjaro_kernel}/core/${manjaro_kernel}
    
    # --------------------------
    # modify build recipe
    # add '-${custom}' to kernel name
    sed -i 's|^_kernelname=.*|_kernelname=\"'${custom}'\"|g' ${pkgrecipe}
    
    # add '-${custom}' to package base name
    sed -i 's|^pkgbase=.*|pkgbase="linux\${_basever}'${custom}'\"|g' ${pkgrecipe}
    
    # add '-${custom}' to the base kernel name
    sed -i 's|\"\${_basekernel}-\${CARCH}\"|\"\${_basekernel}-'${custom}'\${CARCH}\"|g' ${pkgrecipe}
    
    # --------------------------
    # modify kernel config
    # set KBUILD_BUILD_HOST to ${host}
    sed -i 's|^export KBUILD_BUILD_HOST=.*|export KBUILD_BUILD_HOST=\"'${host}'\"|g' ${pkgrecipe}
    
    # set KBUILD_BUILD_USER to ${user}
    sed -i 's|^export KBUILD_BUILD_USER=.*|export KBUILD_BUILD_USER=\"'${user}'\"|g' ${pkgrecipe}
    
    # set kernel config CONFIG_LOCALVERSION to '${custom}'
    sed -i 's|^CONFIG_LOCALVERSION=.*|CONFIG_LOCALVERSION=\"'${custom}'\"|g' ${kernel_config}
    
    # set kernel config CONFIG_DEFAULT_HOSTNAME to ${host}
    sed -i 's|^CONFIG_DEFAULT_HOSTNAME=.*|CONFIG_DEFAULT_HOSTNAME=\"'${host}'\"|g' ${kernel_config}
    
    # update pkgsums
    updpkgsums
    
    # run makepkg with install and cleanup
    PKGDEST=${builddir}/${manjaro_kernel} makepkg -sicC
