#  [[Unstable Update] October 2026](/t/unstable-update-october-2026/190362)

The update wants to change:  
from:  
`GRUB_CMDLINE_LINUX_DEFAULT="udev.log_priority=3 acpi_backlight=native resume=UUID=9f921366-4ebb-4b6b-aa6e-1fa19d252abc"`

to:  
`GRUB_CMDLINE_LINUX_DEFAULT="loglevel=3 quiet rd.udev.log_level=3"`

The final sould be:  
`GRUB_CMDLINE_LINUX_DEFAULT="loglevel=3 quiet rd.udev.log_level=3 acpi_backlight=native resume=UUID=9f921366-4ebb-4b6b-aa6e-1fa19d252abc"`

or

`GRUB_CMDLINE_LINUX_DEFAULT="quiet loglevel=3 rd.udev.log_level=3 acpi_backlight=native resume=UUID=9f921366-4ebb-4b6b-aa6e-1fa19d252abc"`

<https://wiki.archlinux.org/title/Silent_boot#Kernel_parameters>

> Note that this only seems to work if both `quiet` and `loglevel=`_`level`_ are used, and they must be in that order (quiet first). The loglevel parameter will only change that which is printed to the console, the levels of _dmesg_ itself will not be affected and will still be available through the journal as well as _dmesg_. For more information, see [kernel parameters](https://docs.kernel.org/admin-guide/kernel-parameters.html).
