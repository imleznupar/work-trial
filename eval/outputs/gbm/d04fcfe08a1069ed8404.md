# Shellroute: run terminal commands through a proxy by country or city

civilis (Vitas Civilis) October 8, 2026, 12:58pm 1

I built Shellroute, an open-source Go CLI for routing a shell session or a single terminal command through a proxy in a chosen country or city.

The goal is to make country-specific HTTP checks easier without changing the rest of the machine. Other apps and terminals keep their normal connection.

For example:

```
shellroute run DE -- curl -I https://example.com/
```

This works with compatible clients that honor the proxy settings supplied to the command. Browser traffic such as Playwright needs explicit browser proxy configuration.

The CLI is open source. Routed proxy traffic is a paid service.
