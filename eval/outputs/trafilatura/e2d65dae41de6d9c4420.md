# Version 0.63.1 (9 December 2025)[¶](https://numba.readthedocs.io#version-0-63-1-9-december-2025)

This is a patch release of Numba that fixes lowering for non-CPU targets: [#10373](https://github.com/numba/numba/issues/10373).

## Bug Fixes[¶](https://numba.readthedocs.io#bug-fixes)

### Fix lowering for non-CPU targets[¶](https://numba.readthedocs.io#fix-lowering-for-non-cpu-targets)

Non-CPU targets did not provide the `_reload_init` member in their
`CodeLibrary` subclasses. This is fixed by providing it in the
`CodeLibrary`.
